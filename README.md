# repay-simulator
# 借贷模拟器

用 DeepSeek 写的借贷模拟器。

## 这玩意是干嘛的

解决用户无三代（无房贷、无车贷、无下一代）导致的生活无压力、无动力问题。
通过模拟还贷款，激发生活中的动力、行动力。

牛马没有人抽，就要自己抽自己！！！

## 怎么玩

1. 新建一个合同，填你想存的钱数、期限、每月还款日
2. 系统算出一个虚拟债务和每月最低还款额
3. 每次你在现实中真的往银行卡里存了钱，回来点一次"还款"
4. 虚拟债务减少，真实存款增加
5. 到期没还够，差额自动累加到下期，压力翻倍

## 使用

直接打开：https://dididadapapa.github.io/repay-simulator/

数据存在浏览器本地，不上传服务器。换设备数据不互通。

## 功能

- 多合同管理（最多 10 个），可以给每个合同起名，比如"房贷""车贷"
- 按真实日期自动推进还款周期
- 到期未还自动累加到下期
- 支持一个月内多次灵活还款
- 数字千位分隔符，一眼看清
- 移动端适配，手机也能用
